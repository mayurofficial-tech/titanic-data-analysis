# Titanic Data Analysis Project

## 📌 Project Overview
This project focuses on data cleaning and exploratory data analysis (EDA) of the Titanic dataset.

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook

## 📂 Files Included
- Titanic-Dataset_unclean.csv – Raw dataset
- Titanic-Dataset_clean.csv – Cleaned dataset
- project 1.ipynb – Data cleaning & analysis notebook

## 📊 Key Work Done
- Handled missing values
- Data cleaning & preprocessing
- Exploratory data analysis
- Feature understanding

## 🎯 Purpose
This project is created for learning data analysis and portfolio building.
